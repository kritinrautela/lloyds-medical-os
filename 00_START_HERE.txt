WELCOME! This folder contains the complete, 100% offline hospital management
and clinical telemetry system built for Lloyds Metals & Energy Limited (LMEL)
remote exploration and mining concessions in Papua New Guinea.

No internet or cloud setup is required. The system runs directly from this
drive on any Windows PC or Mac laptop.

--------------------------------------------------------------------------------
1. HOW TO START THE SYSTEM (DOUBLE-CLICK)
--------------------------------------------------------------------------------
• ON WINDOWS:
  Double-click:  Start_Hospital_Windows.bat

• ON MAC:
  Double-click:  Start_Hospital_Mac.command

Your default web browser (Google Chrome / Edge / Safari) will open automatically
to: http://localhost:4000

If it does not open automatically, open your web browser and type:
http://localhost:4000

3. MULTI-DEVICE CLINIC WI-FI (TABLETS & LAPTOPS)
--------------------------------------------------------------------------------
To use tablets or multiple laptops in the clinic (Doctor room, Triage desk,
and Pharmacy):
1. Connect all computers to the same local Wi-Fi router (No internet needed).
2. On the main computer running the system, find your IP address (e.g., 192.168.1.50).
3. On other tablets/laptops, open the browser and navigate to:
   http://192.168.1.50:4000
All staff will now access the same live patient records simultaneously.

--------------------------------------------------------------------------------
4. HOW TO CLOSE SHIFT & SAFELY REMOVE THIS DRIVE
--------------------------------------------------------------------------------
At the end of the day or shift:
1. In the application, go to "Shift Reconciliation" (End-of-Day).
2. Count physical cash in the clinic safe, confirm 0.00 variance, and close shift.
3. Print the official A4 Shift Audit Sheet and sign it.
4. Double-click:
   • On Windows : Safe_Pen_Drive_Eject.bat
   • On Mac     : Safe_Pen_Drive_Eject.command
   This guarantees that all patient records and database journals are flushed
   cleanly to disk before you unplug the USB drive.
